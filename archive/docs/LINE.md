# Модель линии: почему тренажёр знает, где едет поезд

Сценарий не задаёт ни скорость, ни время до остановки. Он задаёт **километр**,
на котором начинается эпизод, — всё остальное считает физика.

Это не украшение. Из модели линии вырастают три вещи, без которых тренажёр
остался бы викториной с полосками:

1. **Цена секунды становится буквальной.** Рядом с каждым вариантом написано
   не только «12 с», но и «1,2 км» — столько состав пройдёт, пока проводник
   произносит эту фразу.
2. **Точка невозврата — физическая.** Окно, в которое ещё можно заказать
   медиков на станцию, закрывается не по таймеру, а потому что поезд прошёл
   нужный километр. На полосе маршрута видно, как он в это окно въезжает.
3. **Контенту нечем ошибиться.** Методист не может написать «до Твери
   восемь минут», когда до неё шесть: он указывает километр, а минуты
   считает профиль движения.

## Что подтверждено, а что рассчитано

Разделение важное, и оно продублировано в самом файле линии,
в поле `authoring.assumptions`.

**Из открытых источников (сентябрь 2026):**

| Факт | Значение |
|---|---|
| Длина ВСМ Москва — Санкт-Петербург | 679 км |
| Максимальная скорость | 400 км/ч |
| Время в пути | около 2 ч 15 мин без остановок |
| Состав остановок | Рижская, Петровско-Разумовская, Зеленоград-Крюково, Высоково, Новая Тверь, Логовежь, Садва, Выползово, Валдай, Великий Новгород, Жаровская, Тигода, Горки, Южный, Санкт-Петербург Главный |
| Конструкция трассы | около 70 % земляное полотно, 30 % эстакады, свыше 230 мостов и эстакад |
| Подвижной состав | «Белый кречет», 8 вагонов, 454 места |
| Экстренный тормозной путь свыше 400 км/ч | менее 6500 м (опубликованный ориентир для состава такого класса) |

**Рассчитано нами и подлежит замене при внедрении:**

- километровые отметки станций;
- профиль ограничений скорости по участкам;
- ускорение 0,5 м/с², служебное замедление 0,6 м/с², экстренное 0,95 м/с²;
- стоянка 2 минуты;
- сроки согласования с диспетчером: медики — 5 минут, продление стоянки — 4,
  наряд — 7.

Замедление 0,95 м/с² выбрано не наугад: при нём тормозной путь с 400 км/ч
получается 6498 м — ровно тот порядок, который назван в открытых данных.
Тест `тесты ядра → экстренный тормозной путь` следит, чтобы это не разъехалось.

### Отдельно: тоннелей на трассе нет

В первой редакции сценария «Вагон 4, потеря сознания» связь пропадала,
потому что состав входил в тоннель. Проверка источников показала, что
тоннелей на ВСМ Москва — Санкт-Петербург не предусмотрено, а GSM-R
рассчитан на сплошное покрытие с адресацией до каждого проводника.

Механику заменили на настоящую железнодорожную: канал бывает **занят**
(начальник поезда ведёт переговоры с диспетчером), а окно заказа медиков
закрывается по километру. Выдуманная деталь, даже красивая, на защите
стоит дороже, чем её отсутствие.

## Как считается движение

```
скорость_цель = min(
  ограничение_участка,
  √(ограничение_следующего² + 2·a_служ·расстояние_до_него),   ← тормозим заранее
  √(2·a_служ·расстояние_до_остановки)                          ← и до нуля на станции
)
```

Дальше — прямое интегрирование с шагом в секунду: скорость подтягивается
к цели с учётом ускорения или замедления, координата растёт на пройденное
за секунду. Весь маршрут — около семи тысяч шагов, профиль строится
за миллисекунды и кешируется по паре «линия + рейс».

Результат сходится с опубликованными данными: **2 ч 11 мин без остановок,
средняя скорость 310 км/ч** при максимальной 400. Тест держит это в рамках.

### Обратное направление

Километраж линии всегда считается от Москвы — так его называют в расписании.
Поезд, идущий в Москву, движется по нему в обратную сторону, поэтому внутри
профиля линия зеркалится, а наружу километр возвращается в исходных
координатах. Второй линии с теми же станциями заводить не пришлось.

### Чего в модели нет

Уклонов, кривых, сцепления колеса с рельсом, сопротивления воздуха,
аэродинамики при встречном разъезде. Они изменили бы числа на проценты
и не изменили бы ни одного решения проводника — а сложность добавили бы
существенную. Границы модели названы здесь, а не спрятаны.

## Что это даёт сценаристу

В контексте сценария теперь всего пять полей:

```jsonc
"context": {
  "line": "vsm-msk-spb",
  "service": "express-day",
  "startKm": 126,       // где начинается эпизод
  "car": 4,
  "comms": true
}
```

Из них выводятся: время суток, скорость, действующее ограничение и его причина,
километр, расстояние и время до ближайшей остановки, экстренный и служебный
тормозной путь. Всё это обновляется на каждой секунде рейса — в том числе
пока игрок думает.

Условия доступности варианта тоже стали физическими:

```jsonc
"requires": { "minLeadSec": 300 }   // пока до остановки не меньше пяти минут
"requires": { "maxSpeedKmh": 40 }   // только на стоянке или малом ходу
"requiresWorld": { "minLeadSec": 300 }, "elseGoto": "n-window"
```

Последнее — про целый узел: экран доклада с запросом медиков не открывается,
если окно уже закрыто, и рейс уходит в ветку «окно упущено», где остаётся
резервный путь — просить внеплановую остановку.

import fs from 'node:fs'
const line = JSON.parse(fs.readFileSync('content/lines/vsm-msk-spb.json','utf8'))
const { profile, trainState, brakingDistanceM } = await import('./engine/line.js')
console.log(trainState(line, 'express-day', 126, 0))
