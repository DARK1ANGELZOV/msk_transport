# СМЕНА 400

**Интерактивный тренажёр принятия решений для проводников высокоскоростных
поездов.** Трек «Геймификация для ВСМ», хакатон Московского транспорта.

> ### Не угадай правильный ответ. Прими правильное решение.
>
> Продукт не учит правильному ответу. Он учит видеть последствия решения —
> в том числе те, что приходят не сразу.

---

## Запуск за одну минуту

```bash
git clone https://github.com/DARK1ANGELZOV/msk_transport.git
cd msk_transport/smena400
npm install
npm run db:seed      # создаёт базу и проверяет, что ситуации играбельны
npm run dev
```

Открыть <http://localhost:5173>.

Ни переменных окружения, ни ключей, ни внешних сервисов. Требуется
**Node.js 22.5+** — используется встроенный `node:sqlite`.

Через Docker:

```bash
cd smena400
docker compose up --build     # http://localhost:5400
```

## Что внутри

Проводник попадает в рабочую ситуацию, принимает решения под таймером
и видит, как они меняют развитие событий. Часть последствий приходит сразу,
часть — через несколько шагов, когда связь с причиной уже не очевидна.
В конце разбор показывает эту связь, а из разбора можно **вернуться
к конкретной развилке** и проверить другую стратегию.

```
ситуация → решение → последствие → новая ситуация → итог →
разбор → возврат к развилке → сравнение попыток
```

Пять ситуаций взяты из банка «Примеры ситуаций взаимодействия поездного
персонала с пассажирами» (51 случай). Нормативная рамка — 974-р, 989-р
и 990-р. В каждом сценарии отдельно указано, что следует из источника,
а что является игровой интерпретацией, — и это показано пользователю
прямо в интерфейсе.

## Исходные материалы

Стандарты СТО РЖД (974-р, 989-р, 990-р) и банк «Ситуации на борту» выданы
участникам хакатона и не опубликованы открыто — **в репозиторий они
не включены**. Дословные цитаты, на которые опираются сценарии, приведены
в [docs/SOURCES.md](smena400/docs/SOURCES.md) со ссылкой на документ
и раздел.

Чтобы воспроизвести извлечение текста из банка, положите файлы
в [`materials/`](materials/) — см. инструкцию там.
