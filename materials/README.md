## Извлечение текста из банка

Текст в PDF набран подмножеством шрифта, поэтому обычные извлекатели
возвращают мусор: коды символов начинаются с 33 и без карты `ToUnicode`
не расшифровываются. В репозитории есть скрипт, который эту карту собирает:

```bash
cd smena400
python tools/pdftext.py "../materials/Ситуации на борту.pdf" bank.txt
```

Продукту этот шаг не нужен — сценарии уже написаны. Скрипт лежит здесь
затем, чтобы работу с источником можно было проверить.
